# Security Policy

## Reporting a vulnerability

**Do not report security vulnerabilities through public GitHub issues.** They would be
visible to everyone before they are fixed.

Report a vulnerability through [GitHub's private vulnerability reporting](
https://github.com/Foodshareclub/foodshare-tools/security/advisories/new) — the Security tab of
this repository. Reports reach only the maintainers.

If the private reporting form is unavailable to you, contact a maintainer directly
through the Foodshareclub organization on GitHub and ask for a secure channel.

## Scope

This policy covers this repository and the tooling it ships.

Out of scope:

- Other Foodshareclub repositories — report them in the Security tab of that repository.
- Domain registration and Cloudflare infrastructure operations.
- Third-party services we do not operate.

## Response

- **Acknowledgement** within 72 hours of a valid report.
- **Mitigation or patch** as fast as we can make it safely; 30 days is the target.
- **Coordinated disclosure**: we will not publish a fix without telling you, and we
  credit reporters who ask to be credited.

If a report is not a valid security issue, we will say so and may move it to a public
issue.
